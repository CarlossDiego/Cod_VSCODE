# 🌐 Portfólio — Carlos Diego

Este repositório contém meu portfólio profissional, desenvolvido para apresentar minhas habilidades, projetos, experiências e contato como desenvolvedor.

O site foi criado utilizando práticas modernas de UI/UX, animações suaves, interface premium e responsividade completa para todos os dispositivos.

---

## 🚀 Tecnologias Utilizadas

- **HTML5**
- **CSS3 (UI Premium + Responsividade)**
- **JavaScript (modais, interações e navegação dinâmica)**
- **Google Fonts (Playfair Display e Poppins)**
- **YouTube Embed**
- **WordPress Projects Integration**
- **Python (demonstrações de projetos)**

---

## 🎨 Destaques do Projeto

### 🔸 Design Elegante e Responsivo  
Portfólio com tema **dark premium**, animações flutuantes, efeitos de brilho dourado e componentes visuais refinados.

### 🔸 Navbar Redonda e Fixa  
Interface única com bolhas animadas contendo os links principais.

### 🔸 Seções Apresentadas  
- Banner principal com meu nome e botão de baixar currículo  
- Sobre mim  
- Habilidades técnicas e soft skills  
- Projetos reais desenvolvidos  
- Vídeo de apresentação  
- Formulário de contato  
- Viewer interno com modal (iframe) para cada projeto  

### 🔸 Modais profissionais para demonstrar projetos  
O visitante pode visualizar sites como **Belocaos** e **Cãojunto** diretamente no portfólio.
